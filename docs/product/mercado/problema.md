# O problema

## A dor

O cidadão quer saber como seu representante votou, quantos projetos apresentou e para onde foi o dinheiro público. Hoje ele não consegue. Não é falta de dados. É falta de acesso e de clareza.

Os dados existem e são públicos. A Câmara dos Deputados tem uma base. O Senado Federal tem outra. O TSE tem uma terceira. Cada um com formato próprio, sigla própria e linguagem técnica. Para descobrir como um deputado votou num único projeto, a pessoa precisa cruzar três portais, entender jargão legislativo e montar o quebra-cabeça sozinha. A maioria desiste. A transparência fica no papel.

## O cenário atual

Hoje em sua grande maioria o governo não possui dados centralizados. Quando possui, são de difícil entendimento para pessoas de menor instrução. Os dados dos representantes eleitos são públicos, mas estão espalhados por sistemas independentes, cada um com sua própria lógica e vocabulário.

## Para quem

Cidadão comum que não consegue acompanhar seus candidatos em todos os sites e notícias.

## O que isso implica para o produto

O Meu Candidato não vai expor dados crus. Vou traduzir, agregar e resumir. O que entrego é uma leitura clara do comportamento do político, sem que o usuário precise entender de onde cada dado veio ou o que cada sigla significa.

## O que é o problema

Dados públicos existem. A Câmara, o Senado e o TSE publicam. O problema não está na falta de dados. Está na dispersão e no formato. Cada órgão publica em sua própria lógica, com siglas e linguagem técnica. O cidadão comum não consegue usar esses dados diretamente. Precisa de uma camada de tradução entre o dado bruto e a pergunta que ele faz.
